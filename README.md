# GDUT_Homework - 广东工业大学作业集合

本仓库收集了广东工业大学的部分课程作业和项目。

## 项目列表

### 1. 校园交易平台 (`校园交易平台/`)
- **描述**: 一个面向大学生社群的简单交易平台
- **技术栈**: Python + SQL Server + pyodbc
- **功能**: 用户注册登录、商品发布浏览、交易管理
- **运行方法**: 详见项目内 README.md

### 2. 大学生就业创业指导
- 相关课程作业和资料

### 3. 知识图谱
- 知识图谱相关实验和项目

### 4. 自然语言处理
- NLP 相关实验和代码
